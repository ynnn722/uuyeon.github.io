# Microsoft AI-103(AI-102) study note

### AI란?

AI(인공지능)라는 용어는 애플리케이션이 인간과 유사한 동작을 나타낼 수 있도록 하는 광범위한 소프트웨어 기능을 다룬다. 오늘날 AI는 많은 데이터를 학습하면서 데이터 안의 의미 있는 연결 관계를 파악하고, 그 내용을 담고 있는 기계학습 모델을 기반으로 작동한다.

#### 생성 AI 및 에이전트

생성 AI는 자연어 프롬프트를 입력받아 새로운 응답을 생성할 수 있는 **LLM(대규모 언어 모델)**을 기반으로 한다. 이러한 생성 AI는 대화형 챗봇이나 AI 기반 콘텐츠 제작에 활용되며, 최근에는 AI 에이전트 솔루션의 핵심 기반 기술로 확장되고 있다. AI 에이전트는 LLM에 특정 역할과 책임을 정의한 지침을 결합하고, 필요한 지식을 검색하거나 작업을 자동화할 수 있는 도구를 사용하여 보다 자율적으로 과업을 수행한다.

#### 자연어 처리

최신 LLM은 기존의 **NLP 기술(자연어 처리)**에서 발전한 것이다. NLP는 통계적 방법과 의미 기반 모델을 이용해 문서, 이메일, SNS 글 같은 텍스트를 이해하고 분석하는 AI 분야이다. 지금은 많은 NLP 작업을 생성 AI 기반 LLM이 수행할 수 있지만, 용어 빈도 알고리즘과 같은 통계적 NLP 기법이나 텍스트 분류, 감정 분석, 요약을 위한 텍스트 분석 분야에서는 여전히 전통적인 NLP 기술이나 작업별 특화 모델이 활용된다.

#### 컴퓨터 음성

AI 앱이나 AI 에이전트는 음성을 인식하고 다시 음성으로 응답하는 기술을 통해 사람과 더 자연스럽게 대화할 수 있다. 컴퓨터 음성 기술은 AI의 오래된 분야 중 하나이며, 최근에는 잡음, 말 끊김, 여러 언어와 억양까지 처리할 수 있을 정도로 발전했다. 또한 음성 대화뿐 아니라 녹음 파일 전사, 음성 분석, 실시간 번역, 텍스트 읽어주기에도 활용된다.

#### 컴퓨터 비전

컴퓨터 비전은 이미지, 비디오, 실시간 카메라 스트림과 같은 시각적 데이터를 입력받아 해석하고 처리하는 AI 기술이다. 이를 통해 객체 인식, 상품 식별, 얼굴 인식, 불량 검출, 자율주행 판단 등 다양한 작업을 수행할 수 있다. 예를 들어 자동 체크아웃 시스템은 컴퓨터 비전을 이용해 장바구니 속 상품과 수량을 인식하여 바코드 스캔 없이 결제를 가능하게 한다. 최근 생성 AI 모델은 **멀티모달** 형태로 발전하여 시각적 입력을 처리할 뿐 아니라 이미지나 비디오와 같은 시각적 출력도 생성할 수 있다.

#### 정보 추출

생성 AI, 자연어 처리, 컴퓨터 비전, 음성 인식 기술을 결합하면 문서, 양식, 이미지, 녹음 파일 등 다양한 형태의 콘텐츠에서 핵심 정보를 추출하는 AI 솔루션을 개발할 수 있다. 생성 AI는 언어적 추론을 수행하고, 자연어 기술은 문서의 의미와 구조를 이해하며, 컴퓨터 비전은 이미지나 영상 속 정보를 분석하고, 음성 기술은 음성 데이터를 전사하고 해석한다. 이러한 기술의 결합을 통해 **비정형 데이터에서 필요한 정보를 자동으로 추출**하고 업무를 자동화할 수 있다. 예를 들어 자동 비용 청구 처리 시스템은 스캔한 영수증에서 구매 날짜, 품목별 세부 정보, 총 비용을 자동으로 추출할 수 있다.



### Microsoft Foundry
Microsoft Foundry는 Microsoft Azure에서 AI 솔루션을 개발하기 위한 플랫폼이다. Azure AI 리소스를 개별적으로 프로비전하여 Foundry 없이도 AI 애플리케이션을 개발할 수 있지만, Microsoft Foundry는 **프로젝트 조직, 리소스 관리, AI 개발 기능을 통합적으로 제공**하므로 단순한 솔루션을 제외한 대부분의 AI 솔루션 개발에 권장된다. 
또한 Microsoft Foundry는 웹 기반 시각적 개발 환경인 Foundry 포털과, 프로그래밍 방식으로 AI 솔루션을 개발할 수 있는 Foundry SDK를 제공한다.

#### Microsoft Foundry 프로젝트
Microsoft Foundry에서는 AI 솔루션을 프로젝트 단위로 관리한다.
- 리소스 연결: AI 모델, 데이터베이스, 스토리지 같은 외부 리소스와의 연결
- 데이터: 모델이 사용할 문서, 파일, 데이터셋
- 코드: AI 앱이나 기능을 구현하는 코드
- 기타 요소: 프롬프트, 평가 설정, 배포 설정 등

각 프로젝트는 Azure에 생성된 하나의 Microsoft Foundry 리소스에 소속되며, 이 Foundry 리소스는 컴퓨팅, 데이터 스토리지, AI 도구 및 기타 서비스를 제공한다. 하나의 Foundry 리소스는 여러 개의 자식 프로젝트를 포함할 수 있고, 이 중 하나는 기본 프로젝트로 지정될 수 있다.

Microsoft Foundry의 프로젝트는 AI 솔루션을 만들 때 필요한 모델, 에이전트, 도구, 지식을 관리하는 작업 공간이다. 개발자는 프로젝트 안에서 LLM을 배포하고, 에이전트를 만들고, 도구와 지식 저장소를 연결해서 생성 AI 앱이나 AI 에이전트를 개발할 수 있다.

#### 모델
AI 솔루션의 핵심 기능을 수행하는 대규모 언어 모델, 즉 **LLM**이다. Microsoft Foundry에서는 Foundry **모델 카탈로그**에서 Microsoft OpenAI 및 기타 공급자의 모델을 선택하여 프로젝트에 **배포**할 수 있다. 배포된 모델은 프로젝트 엔드포인트 또는 Azure OpenAI 엔드포인트를 통해 애플리케이션과 연결되어 자연어 이해, 응답 생성, 추론 등의 작업을 수행한다.

- 프로젝트 엔드포인트 : Foundry 관련 API나 SDK를 통해 모델에 연결하는 방식
- Azure OpenAI 엔드포인트 : OpenAI API나 SDK를 통해 Azure OpenAI 모델에 연결하는 방식

#### 에이전트
**LLM, 지침, 도구를 결합하여 작업을 자동화**하고 사용자 또는 다른 에이전트와 협업할 수 있는 **자율 AI 엔터티**이다. Foundry의 에이전트는 Microsoft Foundry 에이전트 서비스를 통해 개발되며, 프로젝트 엔드포인트를 통해 사용된다.

- LLM : 문장을 이해하고 판단하는 두뇌
- 지침 : 어떤 역할을 해야 하는지 알려주는 규칙
- 도구 : 검색, 코드 실행, 파일 처리 같은 실제 작업 수단

#### 도구
에이전트가 외부 기능이나 서비스를 활용하여 작업을 수행할 수 있도록 지원하는 요소이다. Microsoft Foundry의 도구에는 **웹 검색, 코드 인터프리터**와 같은 기본 제공 기능이 포함되며, **MCP(모델 컨텍스트 프로토콜)** 연결을 통해 사용자 지정 도구나 타사 도구와도 연동할 수 있다. 또한 텍스트 분석, 음성 인식 및 합성, 번역, 콘텐츠 이해와 같은 AI 서비스도 Foundry 도구에 포함된다.
